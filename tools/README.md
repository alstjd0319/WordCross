# tools — 단어 가공, 퍼즐 생성

담당: 김민성

개발 PC에서만 실행하는 도구입니다. 앱과 Supabase에는 들어가지 않습니다.

## 예정 스크립트

1. 단어 가공
   - TSL, BSL, NGSL을 합치고 중복 제거
   - 3~11글자 알파벳 단어만 남기기, 난이도 나누기
   - Wiktionary 데이터로 한국어 뜻·영어 정의 초안 채우기, Tatoeba 예문 붙이기
   - 결과: `data/words.csv`
2. 퍼즐 생성
   - 격자 틀 선택 → 슬롯 추출 → 제약 충족(MRV, 전방 검사, 백트래킹)으로 채우기
   - 품질 점수(토익 단어 비율, 중복 등)로 걸러 내기
   - 결과: `data/puzzles/*.json`
3. Supabase 입력
   - 검수가 끝난 단어와 퍼즐을 CSV 또는 SQL로 변환해 입력
